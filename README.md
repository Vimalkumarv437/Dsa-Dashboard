DSA & System Design Learning Dashboard
A personal learning dashboard built with React.js to track my MAANG interview preparation — all in one place instead of juggling spreadsheets and notes apps.
Features

DSA Topic Tracker — track progress across all major topics with status indicators
Problem Solving Tracker — log LeetCode problems by topic, difficulty and date
System Design Notes — notes on core concepts and case studies
Progress Charts — visual breakdown of completion and consistency
Study Roadmap — structured 6-month MAANG preparation plan built in

Tech Stack
React.js, Chart.js, Context API, LocalStorage
Getting Started
bashgit clone https://github.com/Vimalkumarv437/Dsa-Dashboard.git
cd dsa-dashboard
npm install
npm start
Why I built this
Preparing for MAANG requires tracking hundreds of problems and complex system design concepts over months. I built this to keep everything organised in one place and stay consistent throughout the journey.
